## Na czym polegał błąd
ExperienceTabLayout przeszedł z `activeTab` w stanie na wartość wyliczaną z hasha URL-a.
`switchTab` bierze hash z dwuelementowej tablicy TAB_HASHES = ['day-trip','multi-day'],
więc dla idx >= 3 hash jest `undefined` → replaceState czyści hash → tabFromHash('')
zwraca 0 → widok wraca na Overview i klik wygląda na martwy.
Wyprawy z 1–2 opcjami działały dalej, dlatego ani CI, ani szybkie kliknięcie tego nie złapało.

## Mapowanie sprzed naprawy, wierny port z ExperienceTabLayout.tsx @ 670d93f7
const TAB_HASHES = ['day-trip', 'multi-day']
hashForTab(idx)  = idx > 0 ? TAB_HASHES[idx - 1] ?? null : null
tabFromHash(h,n) = h === 'day-trip'  && n > 0 ? 1
                 : h === 'multi-day' && n > 1 ? 2
                 : 0
